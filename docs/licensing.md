# Licensing and SPDX policy

Project-authored source, tests, tools, documentation, and examples are
Apache-2.0 unless a file-level SPDX identifier says otherwise. The root
`LICENSE` and `NOTICE` apply when a text format cannot carry a header without
changing a protocol fixture or generated byte stream.

New C/C++ headers and sources, Python, shell, TypeScript/JavaScript, Markdown,
and editable configuration files must carry `SPDX-License-Identifier:
Apache-2.0` using the format's normal comment syntax. Generated files,
cryptographic/binary fixtures, lockfiles, JSON evidence, patch files preserving
upstream context, and copied third-party sources do not receive injected
headers; their provenance is represented by the SBOM and notices.

Third-party source is not relicensed. `scripts/generate-release-metadata.py`
must succeed before release; it rejects npm packages without a resolved license
identifier, records analyzer dependencies, hashes every local upstream patch,
and emits deterministic notices, provenance, and CycloneDX metadata.
