OPENCONSOLE HOST LAUNCHERS

Windows: double-click "Open OpenConsole on next reboot.cmd".
Linux: double-click or run "Open OpenConsole on next reboot.sh".

The launcher asks before making a one-restart-only firmware selection and asks
again before restarting. It does not change the permanent boot order. If an
exact firmware entry cannot be proven, it can only offer the clearly labeled
firmware-settings fallback. USB insertion does not automatically execute code.

See docs/host-reboot-launchers.md in the OpenConsole source repository.
